
 # ✊✋✌️ Rock Paper Scissors Game

An interactive **Rock Paper Scissors Game** built using **HTML, CSS, and JavaScript**. Play against the computer and enjoy a simple yet engaging experience.

## 🚀 Live Demo

🔗 https://abhay82k.github.io/Rock-Paper-Scissor/

## ✨ Features

* 🤖 Play against computer
* 🎯 Random computer choice logic
* 🧠 Win/Loss/Draw detection
* 🔄 Restart game option
* 📱 Fully responsive design
* ⚡ Instant result display

## 🛠️ Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling
* **JavaScript** – Game logic

## 📂 Folder Structure

```bash
rock-paper-scissors/
│── index.html
│── style.css
│── script.js
```

## ⚙️ How to Run Locally

1. Clone the repository

```bash
git clone https://github.com/your-username/rock-paper-scissors.git
```

2. Open folder
3. Run `index.html` in browser
